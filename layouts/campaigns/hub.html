    {{/* Shared by the three editors below (Sessions, the generic table editor covering Quests/Lore/NPCs/Locations, and Misc.) — this page has no localStorage at all, just an in-memory array fetched once on load, so every add/edit/remove/toggle used to PUT that array straight back with no re-fetch first. Unlike the DM portal's equivalent fix (which merges a local persistent cache against a pulled remote snapshot by per-record updatedAt), this page has no local cache to reconcile — the fix here is simpler: fetch the current server state immediately before every write and apply the mutation to *that*, instead of to whatever was in memory since page load.
